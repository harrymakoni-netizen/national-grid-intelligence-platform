What this is

An AI system that gives an electricity utility a drillable view of its network and finds revenue lost to theft, meter failure and undetected technical loss — built for the data ZETDC actually has: prepaid vending transaction logs, not interval meter reads.

Every number in this interface is generated from a seeded synthetic scenario with known ground truth. There is no ZETDC data in this system, and no relationship with ZETDC is represented. That is deliberate: Section 12 of the specification governs building and validating the entire platform before data access is requested.
